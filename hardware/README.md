# Hardware Integration Scope

The present release is software-only for demonstration safety.

The hardware plan covers:

- approved meter communication interface;
- Raspberry Pi or equivalent edge gateway;
- local buffering and API delivery;
- optional additional submetering;
- future contactor, breaker, smart-socket, or PLC interface for approved non-critical loads;
- isolation, enclosure, auxiliary supply, manual override, interlocks, and protection review.

See `safety_and_control_boundary.md` before any physical implementation.
