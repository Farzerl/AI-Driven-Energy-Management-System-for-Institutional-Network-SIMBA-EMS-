# Public repository scope

This repository was generated from the working SIMBA-EMS adjudication build using an explicit allow-list.

## Included

- maintainable application source;
- dashboard and launcher source;
- public configuration and schemas;
- sanitised sample and simulation data;
- focused Track 3 documentation;
- compact validation and reliability evidence;
- tests and continuous-integration workflow;
- lightweight model routing and configuration.

## Excluded

- Python virtual environment;
- installed dependencies;
- runtime logs, sessions and local state;
- credentials and completed environment files;
- raw institutional smart-meter records;
- large model weights;
- private model and dataset archives;
- compiled Windows executable and shortcut;
- caches and temporary test data;
- old patch manifests and historical hotfix notes;
- pitch-only material and duplicate documentation;
- row-level prediction exports not required for method review.

## Why

The public repository is intended for code inspection, maintenance, architecture review and evidence verification. The working build is supplied separately for the product demonstration.
