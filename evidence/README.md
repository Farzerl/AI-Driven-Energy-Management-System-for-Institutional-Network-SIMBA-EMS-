# Evidence Directory

- `model_validation/`: chronological held-out forecasting metrics.
- `edge_runtime/`: model size and four-horizon inference latency.
- `public_dashboard/`: aggregate UZ study evidence used by the interface.
- `cost_impact/`: tariff and scenario planning outputs.
- `validation/`: tests, JavaScript check, security scan, repository audit, and API smoke test.
- `simulation/`: software-in-the-loop controller outputs when generated.

The release evidence separates measured dataset and model results from software-in-the-loop planning results.
